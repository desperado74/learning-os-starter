# Learning OS 模块切换协议

本协议适用于所有具有长期路线、备考纲领、课程顺序或连续模块的科目。它约束“推进前识别边界、到点主动收尾、在新对话承接下一模块”，不改变模块内日常教学方式，也不把自然语言交接改成表格、回执或状态机。

## 长期主线的权威顺序

规划下一模块前，先确定本科目的长期主线文件。通常按以下顺序取权威依据：

1. 用户当轮明确确认的长期目标或调整；
2. 本科目的长期路线、长期规划或备考纲领；
3. 官方大纲、课程顺序或主教材结构；
4. 当前学习主页、上一模块文件与最近交接。

较新的明确决定可以更新旧路线，但近期错题、临时兴趣、单次进度快慢或模型自己的偏好，不能静默改写长期主线。

## 推进前识别边界

启动、刷新规则或题量变化时，先按 [短期规划协议的独立模块规则](短期规划协议.md#独立模块与容量) 核准未完成模块的总容量；分批呈题不能替代独立模块交接。已落实归属迁移时，以当前独立模块的内容与题目边界判定收尾，不再等待旧总范围完成。

### 内容与教材题双线核对

教材配套题的来源、清单和完成口径统一按 [教材题目执行协议](教材题目执行协议.md)。新会话定位及跨模块前必须读取该协议，并核对当前模块的教材题清单。

讲完内容只表示到达内容边界。当前范围的教材题未完成时，继续本模块题目部分，不能因做过自编题、完成微型实践、保存交接或导入 Anki 就宣布模块完成。暂停或换会话可以保存 partial 交接，但它不是进入下一模块的完成凭证。历史交接保留；发现漏题后将具体题号恢复到当前补题入口，已学内容不重讲。

只有用户明确要求跳过或改序时才改变必做范围，注明决定和去向；普通“继续”、容量缩小、时间估计都不是跳题授权。已明确归入下一模块前置段的题继续按该归属执行，不反复搬迁。

新会话定位当前模块时，同时读取完成条件、确切终止点和下一候选。一次回复的原子块结束不必交接；整个模块到点才正式收尾。

准备展示新的题组、章节、讲次或模块前，先核对它属于当前模块还是后续内容。普通“继续”“ok”只表示继续当前流程，不授权跳过收尾。不要按连续题号或文件编号推断下一入口。

- 仍在本模块范围内：正常推进，不向用户展示检查表。
- 已越出范围但还有本模块任务：核对当前对话中的实际完成、明确跳过和剩余内容，继续真正未完成的任务；旧主页滞后不等于未学习。
- 完成条件已满足：明确告诉用户“本模块到这里结束，现在先收尾”，主动执行下列收尾，不等待用户说“交接”。不因一道错题或缺少掌握证明无限延长模块。
- 当前对话足以判断时不重复询问；范围内任务是否完成确实无法确认时，只问缺失的一点，不猜已完成。

## 到达终止点后的顺序

1. 停止新增教学和出题，明确宣布本模块结束。
2. 用自然语言完成并保存本科模块交接，说明实际完成内容、稳定理解、具体困难、未完成或明确跳过的内容和自然的继续入口；同步更新学习主页。不把“讲过”“带提示完成”写成独立掌握。
3. 按 [Anki公共流程](Anki制卡与导入协议.md) 和本科配置完成收尾；连接失败时保留候选，不阻断交接。
4. 回读已保存的交接与更新入口，确认内容、未完事项和文件路径一致；只留下有长期依据的下一候选及待核事项，不为完成下一模块规划而延长当前对话。无法保存时明确说明，提供可复制的临时交接正文，不声称文件已落盘。
5. 强制给出下节的新对话提醒、实际交接文件链接和已填好的接续提示词，然后结束本模块对话；不展示下一模块第一题、开始预习或讲解下一知识块。

partial交接、暂停保存和只完成内容讲解之后，默认回到未完任务，不能按“已有交接文件”判断可跨模块；即使因暂停而另开对话，也仍承接当前未完模块。

新模块的尺度、实践与小模型决策细则统一见 [短期规划协议](短期规划协议.md)，此处不维护副本。正常承接可由当前叶节点规划端完成。

正式交接完成后按下文[暂停与临时位置](#暂停与临时位置)处理已有临时位置；存在旧位置时标明已收尾，没有时不强制另建书签。Anki 不可用时按本科规则保留候选并说明，不能冒称已导入。

新建交接记录时按下文[学习证据格式](#学习证据格式)添加最小元数据，使 manager 和根控制面能够区分计划、声明与真实学习证据。已有交接不要求批量迁移。

## 模块结束必须换新对话

节点入口按 [节点启动协议](节点启动协议.md) 自行定位职责、进度与停止边界，是第一层保障；下方接续提示词只作第二层强调。即使用户未粘贴提示词，新对话也不能省略节点定位或忽略收尾边界。

这是所有科目的公共停止边界：同一对话说“继续”不能进入下一模块。当前模块任务处理完毕后，智能体主动完成交接与本科收尾，不把“请交接”留成等待用户再次下令的事项；收尾回复必须明确说明“本模块已结束，交接已保存，请在本科目目录新建聊天，并粘贴下面的接续提示词”。只有确已保存时才使用“已保存”，保存异常须如实说明。

用户在已收尾的旧对话中只说“继续”“好”“开始吧”，只能再次提示新建聊天并给出接续入口，不授权继续下一模块。旧对话可补正本模块的交接或回应收尾疑问，但不能借此追加下一模块内容。只有用户明确要求本次不换对话、覆盖这条边界时才按其新决定执行；不能从含糊的继续指令推断例外。

换窗指在同一科目工作目录新建一段独立聊天，不是把旧对话切换显示窗口。默认提供提示词供用户操作，不自行创建、归档或关闭任务，也不声称已替用户打开新对话。这是智能体的执行约束，不声称软件界面具备强制锁定能力。

### 收尾交付的新对话接续提示词

每次收尾提供一个可直接复制的代码块，填写当前实际科目与文件，不让用户自行查找或补占位符。

- 内容：科目绝对路径、已保存且回读核实的交接文件、主页、长期路线/备考纲领、规划导航、唯一题目清单、下一模块文件（若已有）和材料入口。
- 位置：**该代码块必须直接出现在当前聊天的最终回复中，同时写入交接文件**；只给文件链接、只说“已写入”，或要求用户自行从文件中复制，均不算完成。
- 缺项：无某类文件如实省略；尚未规划则明确写“下一模块待规划”，不编造路径；不复制教材全文或整个旧对话。
- 下面尖括号仅供模板说明，实际交付时必须替换。

```text
请在 <本科目绝对路径> 接续学习，本对话只承担接下来一个独立模块。
先读取本科AGENTS.md、规则索引及其指向的最新公共规则，再读取：
交接：<已核实的交接文件绝对路径>；学习主页：<实际路径>；唯一题目清单：<实际路径或说明无配套题>。
长期路线/上级纲领及相关总预算：<按本科规则索引填写适用的实际路径>；规划导航：<实际路径>；下一模块：<实际路径及草案/可执行状态，或待规划>；教材/课程入口：<本科资料索引（若有）、主文字版及索引指向的原件PDF，或实际课程材料路径>。
先核对上一模块实际完成与遗留任务，未完成就恢复原任务；确认可以承接后，依据长期主线（含考频档位标注，如有）、实际材料和完整配套题，按现行容量基准核准下一模块范围与完整工作量。只有当前有效时间和实际速度依据足够时才折算学习日或小时，否则明确不折算；不继承已撤销的固定预算或旧模块估时。不凭模块编号推断完成，不默认重学或直接出题。
简要说明本模块学什么、承接哪里、停在哪里，再按对应课程方式开始；任务结束后保存交接、完成本科收尾，并将填写完整的下一段接续提示词写入交接文件、直接放在最终回复中，再提醒我新建聊天。
```

接收方必须实际读取这些文件，按下节核对连续性，并完成 [短期规划协议](短期规划协议.md) 的材料与容量检查；原窗口的下一候选和提示词不替代这一步。新对话没有旧上下文时依靠交接与真实作答恢复，资料缺失或矛盾只核对缺失点，不猜测进度。

## 交接连续性核对

每次正式交接和下一模块启动，除已有完成口径外，再核对“长期覆盖是否连续、任务状态是否保真”。交接用简短自然语言说明四项，不另建回执表：

- 实际完成的教材小节/讲次与原题范围，区分材料接触、AI示范、带提示及独立作答，引用唯一清单或作答证据。
- 未解决的内容、未做题号与小问、待订正事项；当前必做任务仍未处理时保持partial，不用“基本完成”掩盖。
- 已核剩余内容的接收模块或具体待规划材料位置；已分配原题必须有明确接收模块/前置段且链接同一清单，接收未落实不消除欠题。
- 下一次打开的材料、小节或题号及所需前置；解释与长期主线的衔接，不仅写“继续模块N”。

接收方启动前读取交接和同一清单，核准上一终点、下一起点及必要前置；发现遗漏或冲突先定位真实任务，不凭编号推断覆盖、不重复要求已有可靠作答。综合训练可回访旧知识，但不复制原题状态或把回访当作首次覆盖。暂停保存与预算超量的处理分别按下文[暂停与临时位置](#暂停与临时位置)和 [短期规划协议](短期规划协议.md)，不能等到正式完成才保存。

## 下一模块的主线对齐

规划端在写入下一模块前，必须能够明确回答：

- 上一模块完成了长期主线中的哪一段，是否存在未完成但仍影响后续的内容；
- 长期主线规定的下一阶段是什么；
- 新模块是否出现重复、跳跃、越过前置依赖或无意扩张；
- 本轮是正常承接，还是正在修改长期路线。

正常承接时，在新模块的“规划依据”中用一两句话写明长期位置和承接关系即可，不制作冗长审计报告。

## 重大变数与主动沟通

以下情况可能要求重新讨论长期路线：

- 用户的考试、课程、职业或学习目标发生实质变化；
- 官方大纲、考试科目、课程版本、截止日期或权威材料发生变化；
- 当前模块证明原定前置依赖、阶段顺序或模块跨度明显不成立；
- 关键资料缺失、错误或版本不符，导致原路线无法可靠执行；
- 新暴露的问题不是局部补练可以解决，而会显著改变后续多个模块。

出现重大变数时，不得静默重写长期路线或直接生成偏移后的下一模块。规划端应先向用户说明：原定主线、发现的变化、受影响的后续阶段、可选处理方式及各自影响；与用户讨论确认后，再更新长期路线和下一模块。

普通错题、暂时遗忘、进度快慢、一次复述不完整或局部薄弱点，通常只进入交接中的补练建议，不单独触发长期路线重制。

## 新模块最低要求

每个新模块除范围、材料、完成条件和终止点外，还应在“规划依据”中包含：

- 当前位于长期主线的哪个阶段；
- 它承接了上一模块的什么结果；
- 本模块明确止于哪里，下一长期阶段是什么。

如果本科目尚无独立长期路线，则以现有备考纲领、官方大纲、课程顺序或主教材结构作为临时主线；规划端应在模块中明确采用了哪一个依据，而不是自行发明完整长期路线。

## 暂停与临时位置

### 不使用自动保存

周期 hook 和本地 watcher 不作为日常流程。普通入口不读取 `自动续学片段.md`，也不要求用户或模型计数、确认保存或维护额外状态。

### 临时位置

出现以下任一情况时，智能体先在现有唯一清单或模块中保存已处理范围、未完题号及小问、当前困难和准确下一入口：

- 预计或实际投入明显超出 [短期规划协议](短期规划协议.md) 的模块预算；
- 用户要暂停；
- 上下文承接风险明显。

需要跨会话说明时，留下简短partial交接或下述临时位置。保存不必等待模块完成，不推迟到下次会话补记；不另存第二套逐题状态，也不恢复周期hook或watcher。partial不代表完成，恢复时先回到真实未完任务。

模块中途确有跨会话恢复需要时，可以选择性使用 `learning.py checkpoint` 写入短 `续学位置.md`。它只记录当前位置、当前困难和下一入口，不证明掌握，也不是使用 Learning OS 的前置条件。

保存采用版本检查和原子替换；发生冲突时保留已有文件并核对，不盲目覆盖。没有书签只能说“未记录临时位置”，不能说“没有学习”。

## 学习证据格式

根节点和 manager 的总览只把模块交接与真实作答作为可靠学习证据。主页是当前声明，资料目录证明材料存在；两者都不能单独证明已经学习或掌握。

### 最小元数据

今后新建的模块交接放在本科 `学习记录/`，正式作答或复盘放在本科 `练习/`，文件开头使用：

```yaml
---
kind: module_handoff  # 或 practice_attempt
subject: 示例总管/示例课程
module: 模块01_示例主题
occurred_at: YYYY-MM-DD
result: completed     # 或 partial
---
```

正文仍使用自然语言，说明实际完成内容、理解、具体困难、作答表现和下一入口。不得加入自动掌握分、覆盖率或模型置信度。

- `completed`：本模块指定内容与原题均已处理，或有明确用户决定、已落实的顺延、核实异常处置；不表示独立掌握。
- `partial`：仅内容讲完、仍有无归属欠题，或原题状态待核准。
- 题目范围、作答方式与例外按 [教材题目执行协议](教材题目执行协议.md) 链接唯一清单。
- 不存在真实答案时不能编写`practice_attempt`。模块内已有总结可作为来源引用，但维护者不能把文件声明升级为亲见作答。

### 证据强度

- `practice_attempt`：用户真实独立作答及其复盘，可支持具体能力判断。
- `module_handoff`：能证明某段学习实际发生及其结果，但不自动等于长期掌握。
- `学习主页.md`：用于当前定位和声明，不单独作为掌握证据。
- 课程资料、模块计划、文件时间和会话原文：只作来源或追溯线索。

### 题目证据

题目或小问的状态按 [三列记录法](教材题目执行协议.md#题目状态的三列记录法) 表达：“用户自报会做，主动免做”不等于独立掌握证据，“独立作答但有错误”仍是有效真实作答证据。已有记录不要求批量迁移；自然触及旧模块时可补元数据，不为总览完整而改写历史结论。
