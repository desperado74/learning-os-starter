## 唯一任务记录

### A：二级标题

题目：把“今日目标”写成 Markdown 二级标题。

原始作答：

```markdown
## 今日目标
```

帮助方式：无提示。

反馈依据：二级标题使用两个井号和空格，与自编材料一致。

处置决定：本轮独立完成。后续动作：无本轮补做任务，不据此推断长期掌握。

### B：链接

题目：写一个 Markdown 链接，显示文字为“我的进度”，目标为 `学习主页.md`。

首次作答：

```text
(我的进度)[学习主页.md]
```

得到的提示：显示文字用方括号，目标用圆括号；顺序是先文字再目标。

提示后的作答：

```markdown
[我的进度](学习主页.md)
```

反馈依据：提示后的写法与材料一致，首次作答的括号位置颠倒。

帮助方式：提示后完成。

处置决定：需要独立验证。不能写成无提示完成。

后续验证题：写一个 Markdown 链接，显示文字为“本轮交接”，目标为 `交接.md`。

验证作答：未作答。先呈现验证题，不先提供答案。
