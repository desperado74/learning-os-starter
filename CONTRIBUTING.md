# 反馈与贡献

这个项目处于早期版本阶段。请在 [Issues](https://github.com/desperado74/learning-os-starter/issues) 反馈问题，也可以提交具体修改。

建议反馈包含：使用的工具与文件版本、执行步骤、实际结果、期望结果。可以使用示例数据复现，移除个人资料。

文字、链接等小修复可以直接提出具体修改。改变文件职责、模板字段或学习流程时，先说明实际卡点和改法，再讨论范围。

验证结论需要附执行方式与结果。不要把文件检查通过写成 AI 接续已经可靠，也不要把虚构示例记成真实学习效果。

## English

This project is an early release. Report problems in [Issues](https://github.com/desperado74/learning-os-starter/issues), or propose a specific change.

Include your tool and file version, steps, observed results, and expected results. Use example data and remove personal information. Small wording and link fixes are welcome; discuss the use case before changing template fields or the learning workflow.

Describe how you validated a change. A file check does not prove reliable AI continuation, and fictional examples are not evidence of learning outcomes.
