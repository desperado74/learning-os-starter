# 可选 Anki 收尾

默认关闭。用户明确选择Anki并配置自己的牌组后，才在叶节点按真实纠错、易混条件和高价值记忆点筛选候选。零张卡正常；卡片不替代计算、证明、代码实践或原题。

先保存并回读学习交接，再处理卡片。纯文本候选使用front、back、extra、source、tags；题面和答案须含关键条件，来源可定位，一张卡一个检索目标。不得携带作者牌组或账号配置。

导入先预览候选、目标牌组、字段、模板、已有重复及同题不同答案冲突。用户明确授权后才写入；同题不同答案不自动覆盖，已有笔记按note ID修订以保留复习历史。导入后回读note ID、字段、标签、牌组与实际卡数，确认后才能说成功。

连接、认证或限流失败立即停止，保留候选并解释；不自动启动应用、不转UI、不改投其他牌组。结果未确认或超时先核对已有内容，不盲目重复添加。失败不阻断模块交接。

## 工具入口

新用户自行安装Anki及[AnkiConnect](https://foosoft.net/projects/anki-connect/)，并自行启动。工具仅连接本机127.0.0.1:8765，不自动启动应用、不收集密钥或传输到远程。未启用时不运行导入命令。

在当前叶节点建立自己的Anki/配置.json，例如：

```json
{"enabled": true, "deck": "我的课程", "notetype": "Basic", "tags": ["LearningOS"]}
```

候选JSONL每行一张笔记，示例是虚构材料：

```json
{"front":"平均值怎样计算？","back":"总和除以数量。","extra":"数量必须大于零。","source":"虚构课程模块01","tags":["模块01"]}
```

从私人工作区根目录运行，替换成自己的实际节点：

```sh
python3 tools/anki/import_to_anki_connect.py 科目/我的课程/Anki/待导入/候选.jsonl --config 科目/我的课程/Anki/配置.json
# 默认只预览，本机AnkiConnect必须已经可用
# 核对结果并授权后，上一条命令加 --apply
```

仅离线导出TSV时使用tools/anki/build_anki_import.py；导出文件不是导入成功。导出器按题面去重，不替代导入器的冲突检查；不要用它绕过同题不同答案审核。

已完成离线假API回归测试，包括预览不写入、重复与内容冲突、模板兼容、HTML转义、导入后回读及未确认ID拒绝。未连接真实Anki验证，不宣称真实导入已成功。数学格式参考 [Anki官方文档](https://docs.ankiweb.net/math.html)。
