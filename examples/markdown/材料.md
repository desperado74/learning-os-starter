# 示例材料：三个 Markdown 写法

本文件为项目自编的演示材料。

二级标题是在标题文字前写两个井号和一个空格，例如：

```markdown
## 本轮目标
```

链接的写法是方括号内放显示文字，紧接圆括号内放目标。例如：

```markdown
[主页](学习主页.md)
```

无序列表的一种写法是在每项前写短横线和空格，例如：

```markdown
- 阅读
- 练习
```
