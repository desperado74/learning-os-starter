# 可重建本地索引 / Rebuildable local index

## 中文

Markdown是唯一学习事实来源。可选SQLite缓存帮助定位文件，不证明已学、完成或掌握，不影响课程推进。

从私人工作区根目录运行：

```sh
python3 tools/build_index.py
# 默认只读预览文件数，不创建数据库
python3 tools/build_index.py --apply
# 显式重建 数据层/catalog.sqlite3
```

仅登记科目目录中的主页、路线入口、当前模块、交接和练习。排除教材/资料、Anki、画像、隐藏目录、符号链接和会话日志。保存相对路径、内容指纹、大小及开头有效元数据，不保存原文。

证据类型只来自闭合的文件头；正文中的模板例子不是证据。元数据只说明可以找到记录，需读取原文核对。重建会去除已删除文件的旧条目；失败保留旧库，不修改源Markdown，不自动重试或运行后台监控。缓存本身属于私人数据，不发布。

## English

Markdown is authoritative. The optional SQLite cache stores file locations, hashes, sizes and valid leading metadata; it does not store document bodies or establish mastery.

Run the first command above to preview counts without creating a database. Add `--apply` to explicitly rebuild the private cache. It indexes only scoped course entry points, modules, handoffs and practice records. Materials, Anki files, profiles, hidden paths, symlinks and chat logs are excluded.

Body examples never become evidence metadata. Read the original files before judging learning. Rebuilds remove deleted entries; failures preserve the previous cache and never modify source Markdown. No daemon, model call or automatic retry is involved. Keep the cache private.
