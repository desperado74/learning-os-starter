# 本地初始化 / Local initialization

## 中文

这是完整系统候选的初始化组件，尚未替代远程首发的手动模板流程。生成目录已包含通用控制面、规划/教材/交接协议、只读教材工具、可选Anki适配器和SQLite索引工具。完整虚构文件周期与离线工具测试通过，实际agent与真实Anki行为尚未验证。详见 [系统架构与实现](系统架构与实现.md)。

新用户可以请自己的本地 agent 读取本文，分步讨论并填写信息。首次先问想学什么、当前起点和目标，再问爱好、习惯与教材。可跳过任何画像项，不需要姓名、邮箱、密钥或原有聊天。只讨论用户提供的材料路径，不扫描电脑寻找个人资料。

agent 与用户确定课程层级：简单课程直接是 leaf；需要协调多门子课程时建立 manager。不要把文件夹分类误当管理节点；叶节点下面不能再建立课程。

配置保存在公开仓库外的私人目录。以下内容全部为虚构示例；用户需自行替换。`parent` 为已声明 manager 的相对节点路径，父节点先写。材料只记录路径或链接，不在初始化时读取、复制或上传。

```json
{
  "schema_version": 1,
  "profile": {
    "goals": "理解科学基础",
    "interests": "自然现象",
    "habits": "先看例子，再自己解释",
    "available_time": null,
    "language": "中文"
  },
  "nodes": [
    {"name": "科学", "role": "manager"},
    {"name": "入门", "parent": "科学", "role": "leaf", "materials": []}
  ]
}
```

从下载的公开仓库运行（Python 3.9+，无第三方依赖）：

```sh
python3 tools/init_workspace.py --workspace ../my-learning --config ../my-learning-input.json
```

默认只展示待生成的相对文件清单，不写文件，不打印画像和教材路径。agent 解释清单后，由用户确认再执行相同命令加 `--apply`：

```sh
python3 tools/init_workspace.py --workspace ../my-learning --config ../my-learning-input.json --apply
```

目标必须是一个尚不存在的目录、父目录必须已存在、必须在公开仓库与任何现有 Git checkout 之外，也不能通过符号链接跳转。已有目录一律拒绝，不提供覆盖选项；不要对正在使用的系统尝试初始化。

生成私人画像、根管理入口、规则索引及 manager/leaf 节点。没有核材料就不预填当前模块，不生成虚构作答。打开生成的私人目录或指定叶节点，让 agent 先读取入口、核对材料和实际起点，再规划学习。`AGENTS.md` 是 Codex 的指令入口；Claude Code 的 `CLAUDE.md` 导入同目录的 `AGENTS.md`，两者维护同一套规则。官方机制见 [Codex 指令发现](https://learn.chatgpt.com/docs/agent-configuration/agents-md)及 [Claude Code 记忆与导入](https://code.claude.com/docs/en/memory)。入口存在不等于当前 agent 已读取，首次请它列出实际读取的入口。

本工具不配置 agent 登录、不改变全局设置、不启动 hook/watcher、不读取会话、不调用模型、不导入 Anki、不建立数据库。新工作区忽略全部内容，但 `.gitignore` 不能阻止人为强制上传，私人文件不属于公开发布清单。

## English

This is the initializer for the full-system candidate. Generated workspaces include the generic runtime, planning/material/handoff protocols, a read-only material tool, an optional Anki adapter and a SQLite index builder. Fictional file-cycle and offline tool tests pass; actual agent and real Anki behavior remain unverified. See [architecture and implementation](系统架构与实现.md).

Ask your local agent to discuss your goals, courses and starting point first, then your interests, habits and materials. Profile fields are optional; unknown values stay unknown. No name, email, credentials or chat history is needed. The agent should inspect only material paths you explicitly provide.

Use a leaf for a course and a manager to coordinate child courses. Parents must appear before children in the JSON example above. `parent` is a relative manager path. Material values are references only, never copied or uploaded during initialization.

Save your configuration outside the public checkout. Run the first command above from the downloaded repository with Python 3.9+. It is a dry run: it lists generated filenames without writing files or printing private values. Review the list with the agent, then explicitly confirm creation using `--apply`.

The workspace must be new, outside existing Git checkouts, and have an existing parent directory without symlink redirection. Existing workspaces are always refused. Never initialize over an active learning system.

Open the generated private workspace or selected leaf in your agent. Read its instructions, verify materials and establish the actual starting point before planning a module. Codex uses `AGENTS.md`; Claude Code imports it through `CLAUDE.md`, as described in the official documentation linked above. Ask your agent to identify instructions it actually read; file presence alone proves nothing about loading.

The initializer does not change agent authentication or global settings, start hooks, collect chats, invoke models, import Anki or build an index. The generated workspace ignores all its contents in Git, but users can still override that protection manually. Private files are excluded from the public release.
