# 来源与设计取舍

这份样稿由个人 Learning OS 的实际需求提炼而来：文件保存当前状态，真实作答支撑判断，新聊天从明确位置接续。

公开项目调研的参考与借鉴点：

- [OSSU](https://github.com/ossu/computer-science)：说明受众、顺序与范围。
- [Developer Roadmap](https://github.com/nilbuild/developer-roadmap)：按读者目标组织入口。
- [System Design Primer](https://github.com/donnemartin/system-design-primer)：用练习和示例帮助核对学习结果。
- [Superpowers](https://github.com/obra/superpowers)：呈现 AI 使用流程与工具入口。
- [Best README Template](https://github.com/othneildrew/Best-README-Template)：介绍、快速开始、演示和贡献结构。
- [CSAPP 中文 Markdown](https://github.com/SunnyMaria/csapp-zh-markdown)：围绕明确学习材料组织正文与配套内容。

借鉴结构和使用思路，样稿文字与 Markdown 演示材料为本项目编写。未复制第三方教材正文或程序。

第一版将逐题状态放在当前模块，主页和交接只保留短摘要及入口。这样可以检查上下文，又减少状态重复。今后规模扩大时，再根据真实需求考虑单独的题目记录文件。

平台支持通过实际验证说明；AGENTS.md 自动读取与普通聊天附件读取不能混为一谈。当前用显式提供 AI 使用说明的方式，避免依赖未经验证的自动入口。

本项目原创文件采用 [MIT 许可](../LICENSE)。参考链接中的第三方项目保留各自许可；本项目未复制其教材正文或程序。

## 完整系统候选的来源（2026-10-02）

通用协议、控制面、只读教材工具、Anki格式与导入工具由作者自己使用的Learning OS代码和规则适配而来；公开版本独立开发，去掉作者路径、教材表、历史项目、会话采集和自动启动应用。原系统未修改，公开代码不会反向同步其数据。

SQLite元数据缓存、隔离初始化及完整虚构重放是公开版本的独立实现。所有演示资料和答案均为项目编写，不复制真实课程、教材或用户作答。方法中的个人默认值由新用户自行确认。

AnkiConnect为用户另行安装的外部插件，不捆绑其程序；参考 [项目主页](https://foosoft.net/projects/anki-connect/)，其代码和许可归上游。本项目只包含自己的本地客户端适配器。Codex与Claude Code由用户自行安装和登录，不捆绑账号配置。

The full-system candidate adapts the author's own Learning OS protocols and tools into an independent public package. It removes personal paths, material inventories, historical projects, session ingestion and application launching. Initializers, metadata indexing and fictional replay operate independently; no source-system migration or reverse synchronization is involved. External agents and AnkiConnect are installed separately and retain their own licenses.
