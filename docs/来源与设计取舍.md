# 来源与设计取舍

这份样稿由个人 Learning OS 的实际需求提炼而来：文件保存当前状态，真实作答支撑判断，新聊天从明确位置接续。

公开项目调研的参考与借鉴点：

- [OSSU](https://github.com/ossu/computer-science)：说明受众、顺序与范围。
- [Developer Roadmap](https://github.com/nilbuild/developer-roadmap)：按读者目标组织入口。
- [System Design Primer](https://github.com/donnemartin/system-design-primer)：用练习和示例帮助核对学习结果。
- [Superpowers](https://github.com/obra/superpowers)：呈现 AI 使用流程与工具入口。
- [Best README Template](https://github.com/othneildrew/Best-README-Template)：介绍、快速开始、演示和贡献结构。
- [CSAPP 中文 Markdown](https://github.com/SunnyMaria/csapp-zh-markdown)：围绕明确学习材料组织正文与配套内容。

借鉴结构和使用思路，样稿文字与 Markdown 演示材料为本项目编写。未复制第三方教材正文或程序。

第一版将逐题状态放在当前模块，主页和交接只保留短摘要及入口。这样可以检查上下文，又减少状态重复。今后规模扩大时，再根据真实需求考虑单独的题目记录文件。

平台支持通过实际验证说明；AGENTS.md 自动读取与普通聊天附件读取不能混为一谈。当前用显式提供 AI 使用说明的方式，避免依赖未经验证的自动入口。
